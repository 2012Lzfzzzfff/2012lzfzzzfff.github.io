# Personal website of Zhifei Lyu

Live at https://2012lzfzzzfff.github.io (GitHub Pages, no build step).

- `index.html`: all content. Each section is marked with a comment; commented-out templates show how to add a
  publication entry or the Scholar, ORCID, LinkedIn and CV links.
- `style.css`: layout and colours (change `--accent` at the top to change the colour scheme; dark mode follows the
  visitor's system setting).
- `files/`: photo, CV and paper PDFs, linked from `index.html` as `files/<name>`.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

Update: edit `index.html`, commit, push; the site refreshes within a minute or two.
